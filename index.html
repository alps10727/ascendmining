Yayına alalım mı?

Repo oluştur → index.html ekle → GitHub Pages aç → domain bağla → HTTPS’i zorunlu yap. Aşağıda adım adım verdim.

Yayın adımları Whitepaper düzenle

GitHub’dan Yayına Alma + Domain Bağlama

Aşağıdaki adımlar ascendcoin.app alan adını GitHub Pages’e bağlar. (Tek dosya site için ideal.)

Adım 1 — GitHub Repo

  1. GitHub’da yeni repo aç: örn. ascendcoin (Public önerilir).
  2. Bu dosyayı index.html adıyla repo köküne koy.
  3. Commit & push.

Adım 2 — GitHub Pages Aç

  1. Repo → Settings → Pages
  2. Build and deployment → Source: Deploy from a branch
  3. Branch: main / (root) seç
  4. Kaydet → GitHub sana bir URL verir (ör. username.github.io/...)

Adım 3 — ascendcoin.app domain bağla

GitHub Pages ekranında Custom domain alanına ascendcoin.app yaz. Kaydet.

Adım 4 — DNS kayıtları (Domain panelinde)

Domain sağlayıcında (nereden aldıysan) aşağıdaki kayıtları ekle:

A @ → 185.199.108.153
A @ → 185.199.109.153
A @ → 185.199.110.153
A @ → 185.199.111.153

(Opsiyonel) CNAME www → username.github.io

Sonra GitHub Pages’te Enforce HTTPS seçeneğini aç (sertifika gelince aktif olur).
